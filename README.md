# Análise de Vendas com SQL

## Descrição

Projeto desenvolvido para praticar SQL utilizando criação de tabelas, inserção de dados e Stored Procedures para automatização de consultas e geração de relatórios analíticos.

O banco de dados simula vendas agrícolas, permitindo análises de quantidade vendida e faturamento por produto.

---

## Objetivos do Projeto

- Praticar comandos SQL
- Criar tabelas e inserir dados
- Desenvolver Stored Procedures
- Realizar consultas analíticas
- Organizar projetos para portfólio no GitHub

---

## Tecnologias Utilizadas

- SQL
- MySQL
- Git
- GitHub
